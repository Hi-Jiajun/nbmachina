# M3-35 · 混音平衡（A/B 耳测未过 → 默认关）（2026-09-19）

用户问“混音平衡是干啥的” → 解释后要求“把做了平衡和没做平衡的让我看看效果”。

## 1. 做了什么

`tools/render-ensemble.mjs` 新增 `--balance <off|piano1>`（**默认 `off`**）：
只改“层间配比 + 声像”，不碰谱面/音色/力度/总响度（总线仍归一 −18dBFS + 软限幅）。

| 层 | A（现状 `off`） | B（`piano1`） | 变化 |
|---|---|---|---|
| 旋律 | ×1.00 / 居中 / −19.1 LUFS | ×1.18 / 偏右 0.05 / −17.0 LUFS | +2.1dB |
| 内声部 | ×1.00 / 居中 / −20.1 LUFS | ×0.82 / 偏右 0.12 / −21.0 LUFS | −0.9dB |
| 左手低音 | ×1.00 / 居中 / −17.7 LUFS | ×0.72 / 偏左 0.08 / −19.8 LUFS | −2.1dB |

动机是实测出来的：**A 里左手比旋律响 1.4dB**（伴奏盖主旋律），B 把关系翻成旋律领先 2.8dB
（相对差 +4.2dB），更接近“一台真实钢琴”的层次。声像给得极小，对应真实钢琴“低音弦在左、
高音在右”。

## 2. 顺带更正一个错误量法

上一轮汇报的“单声道下混 +2.82dB 爆表”来自 ffmpeg `-ac 1` 的**功率守恒下混**（自带 +3dB），
不是真的削顶。改用真正的 (L+R)/2 下混重测：A 峰值 **−0.2 dBFS**、B **−0.3 dBFS** ——
**从来没有削顶问题**。这条更正已同步给用户。

## 3. 验证

- `--balance off` 的输出与既有母版 **MD5 逐字节相同**（`4892C45E…`）→ 默认口径零漂移；
- 总响度 A −14.9 / B −14.8 LUFS（差 0.1dB）→ A/B 听感对比不受音量差干扰；
- 三条 stems 与总线同一套 gl/gr，stems 可直接重配比。
