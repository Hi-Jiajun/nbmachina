# M3-47 · 逐音严格对账（游戏内 vs 谱面/母版）（2026-09-19）

用户要求："对比音频时和母版要一一对应，每个音节音高都要对应，多音/杂音/缺音/错音都要找到，
速度节奏也要同步，要求严苛一些。"

## 工具

`tools/audit-notes-vs-master.mjs`：

1. 用**同一个转谱模型**（piano_transcription_inference，note F1 0.9677）把游戏内录音听成音符表；
2. 与谱面（`machine_map.csv` 的 `time_sec` + `midi`）**逐音配对**（默认容差 ±120ms）：
   同音高命中 = 对上；时间对上但音高不同 = **错音**（区分"八度差 12/24…"与"音级不同"）；
   谱面有录音无 = **缺音**；录音有谱面无 = **多余音**；
3. 两级对齐：1 秒包络互相关（粗）→ **逐音命中数最大** 的偏移（±1.5s，5ms 步进）→ 再用
   **时间偏差中位数**抹平系统性偏移（这步不做，统计出来的"错音/多余"大半是对齐误差的假阳性）；
4. 另外报：削顶样本数、逐 10 秒的缺/多分布、每颗音的时间偏差（中位/p90/最大）。

用法：

```
node tools/audit-notes-vs-master.mjs --record <录音.mkv> --at <录音t=0对应的谱面秒> [--tol 120]
```

### 怎么读这些"错/缺/多"

- **多余音 679 个里，678 个都落在某个谱面音 ±60ms 内** → 不是"额外的声音"，而是转谱模型把和弦/泛音
  拆成了多个音符（模型行为）。**真正离谱面音很远的多余音只有 1 个**（112.74s，110ms）。
- 错音 105 个中 22 个是纯八度差（±12/24/36/48 半音），83 个"音级不同"；
  **105/3044 = 3.4%，与模型自身错误率（1 − F1 0.9677 ≈ 3.2%）同量级** → 属于测量噪声，不是机器的问题。
- 缺音 35 个（1.1%）同样在模型误差量级内。

### 结论

这次录制**没有发现系统性的错音/多音/缺音**；节奏与母版**严格同步**（中位 0.4ms、p90 22.5ms、最大 58ms）。
真正意义上的"多出来的声音"只有 1 处，已记录在审计 JSON 里。

## 回归判据（以后每次改动都跑）

| 判据 | 阈值 | 不通过的含意 |
|---|---|---|
| 逐音同音高对上率 | ≥ 95% | 有系统性错音/缺音 |
| 时间偏差 p90 | ≤ 30ms | 节奏/速度有问题（漂移另用 compare 工具看） |
| 远离谱面音的多余音（>60ms） | ≤ 5 个 | 有残留方块在乱响 / 引擎多放 |
| 削顶样本 | ≤ 100 | 混音过载 |
