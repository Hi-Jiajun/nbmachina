# M3-50 · 严格逐音审计：判定 **+ 解决方案**（2026-09-19）

用户要求两条："不够严格" 以及 "不能只给判定，要有解决方案"。

## 为什么不能用转谱模型

`tools/audit-notes-vs-master.mjs`（用 piano_transcription_inference 转谱再比对）给出"对上率 95.4%"，
但这个模型自身 note F1 = 0.9677 → **错误率 ~3.2%**，正好把 1~3% 的真问题盖住。**不够严格，作废为辅助**。

同样否掉的还有"录音 vs 母版逐格比电平"：母版是离线母带（42Hz 高通 + 归一化 −18dBFS RMS + 软限幅），
游戏内引擎是原始采样 + 逐音增益、无总线处理，两条链路每带差 ±5dB → ±6dB 判定会造出 1216 个假"缺音"。

## 严格工具：`tools/audit-onset-vs-score.mjs`

判据全部来自信号，不依赖模型：

| 检查 | 做法 | 判读 |
|---|---|---|
| **逐音音频证据** | 每颗谱面音取自己的谐波梳（f0 的 1–4 次，±3%），比"起音后 20–170ms"与"起音前 150–10ms"的能量；或与本地底噪比 | 升起 ≥1.5× 或高出本地 ≥1.5× = 这颗音在录音里**确实响了** |
| **节奏** | 用起音时间减去谱面时间 | 中位/p90/最大（阈值 p90 ≤ 30ms） |
| **错音** | 同时刻（±60ms）的谱面音**分组成和弦**，取起音后 40–200ms 的 12 音级 chroma，要求组内每个音级都落在前 k+2 强 | 缺哪个音级就报哪个音级 |
| **多余起音** | 起音 ±60ms 内没有任何谱面音 | 候选"多出来的声音"（残留方块 / 双触发 / 分析误报） |
| **解决方案** | 把上面每类问题按机器 x 区间聚合（x ≈ 480 + step），并给可执行动作 | 见下 |

## 解决方案（工具直接输出）

| 问题 | 动作 |
|---|---|
| 多余起音（残留方块/双触发） | 按区间跑 `/function styx:wipe`（过滤式清方块）或让 mod 清（`/nbm cleanstrays`），随后 `styx:redo` |
| 错音中"邻居顶替"那 226 处 | 跑 `node tools/verify-trigger-map.mjs` 查触发位是否重复/越界；再 wipe + redo |
| 证据不足的音 | 先 `node tools/install-samples.mjs --check` 核对采样是否缺文件；再按区间 wipe + redo |
| 节奏超标（p90 > 30ms） | 工具直接给出补偿命令：`/nbm machine start 0 <offsetMs> <rate>`（本次 p90 = 17ms，**无需补偿**） |

## 仍需注意

- "错音 377"里绝大多数是**和弦 chroma 分析本身的局限**（低音轰鸣会压住上方音级），不是机器错音；
  真正需要查的是那 226 处"与邻近谱面音音级一致"的线索。
- "多余起音 73" 是**候选**：既可能是残留方块/双触发（真问题），也可能是长音泛音被起音检测器当成新起音。
  下一步：对这 73 处逐个做"该时刻录音 vs 母版的 1/6 倍频程差异"复核（母版在该时刻没有任何谐波 → 判真多音）。
