# nbforge M1「修音乐性」Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development。每条任务必须 TDD + 小步提交 + 报告里贴原始输出。

**目标**：M0 修完的是"参数"（八度/撞格/力度口径），M1 修**听感**：错音、断奏、重音。全程以 `build/styx_helix_full.wav` 为基准，任何改动都要能被 `src/verify/score.mjs` 量出来。

**当前最优谱面**：`build/styx_helix_machine.csv`（2802 音，客观分 0.9467，撞格 0，已进机器且无头验收全绿）。

**流水线位置**（不许跳过）：`notes_fixed_v3.csv`（T3 八度修好）→ **T1 音级恢复** → `fold.mjs`（重折 0..24 行）→ `velocity.mjs`（T5 力度）→ **T2 长音重复触发** → `dedupe.mjs`（撞格 0）→ `emit/datapack-playback.mjs`。

## Task 1 · 音级恢复（把被吸附的 5 个调外音级找回来）
**问题**：v3 谱面被吸附到 C# 自然小调，调外音级（C/D/F/G/A#）在音频里占最大音级的 0.16–0.57，谱面只有 0.01–0.06（差 3–11 倍），合计仅占谱面质量 3.4% → 用户听到的"错音"主要来自这里。
**Files**：`src/arrange/pitch-fix.mjs`（新增）、`tests/pitch-fix.test.mjs`（新增）、`docs/M1-1-report.md`
- [ ] 失败测试：合成"每颗音在 12 个音级上各有一个窄带能量峰"的输入，函数必须选中真实音级；证据不足时**保持原值**并记 `degradations`
- [ ] 实现：对每颗音（`step/instrument/midi`），在**它自己的八度**上量 12 个音级的窄带能量（复用 `src/analyze/dsp.mjs` 的 `narrowbandEnergy`），取最强音级；只有当"最强/次强 ≥ 1.6 且它与原音级不同"才改，输出 `midi'`（保持八度不变、只换音级）+ `reason`
- [ ] 验收（必须贴原始输出）：调外音级质量占比 **3.4% → ≥8%**；与音频逐音级占比的差 **<2×**；`score.mjs` 客观分 **≥0.9467 不下降**；八度命中率不下降
**验收命令**：`node src/arrange/machine-pipeline.mjs --in <pitch-fix 输出> --out build/machine_p1.csv && node src/verify/score.mjs --notes build/machine_p1.csv --octave-evidence build/analysis_octave.json`

## Task 2 · 长音/延音（原版音符盒没有延音，靠同音重复触发）
**问题**：MIDI 输入每颗音的时值都是 0.05 拍（触发脉冲），数据层面没有长音；原版音符盒响 1 拍就衰减完 → 旋律全是断奏，用户抱怨的"不连贯"。
**Files**：`src/arrange/sustain.mjs`（新增）、`tests/sustain.test.mjs`（新增）、`docs/M1-2-report.md`
- [ ] 失败测试：给定"音频包络持续 0.6 s"的合成输入，函数必须在同音高上按 2 步间隔追加重复触发；持续 0.12 s 的短音不得追加
- [ ] 实现：从 WAV 估每颗音的持续长度（起音后带内能量跌破起始值 25% 的时刻，上限 1.0 s），把 >0.36 s 的音拆成"首触发 + 每 2 步一次重复触发"，重复音力度按 0.85 逐次衰减，并标 `sustainOf`
- [ ] 验收：重复触发次数与"音频持续时长"的相关 **r ≥ 0.6**；新增触发数写进报告；客观分不下降；**撞格仍为 0**

## Task 3 · 力度对齐"重音"（当前 vsOnsetStrength = −0.53）
把 `velocity` 口径从"该音级该八度的窗内能量"改成"**起音瞬间该音带内的冲击强度**"（攻击段能量 / 前 30 ms 斜率），目标 `vsOnsetStrength > 0.5`，同时不破坏"同一步内力度不再全相同"。

## Task 4 · 一键回退（undo 前像快照）
`emit` 生成包时同时产出"将被改动的每一格的前像"（方块 id + 状态），生成 `styx:undo`；验收：故意改错 3 处 → `styx:undo` → 逐格差异 **0**（现在的 `undo.mcfunction` 只有 3 行 + 硬编码 fill，无法证明）。

## Task 5 · 一条命令流水线
`npm run arrange` 串起 T1→fold→velocity→T2→dedupe，输出 `build/manifest.json`（每步输入输出 sha256 + 计数），任一步失败即非 0 退出。当前需手工跑 4 条命令，容易漏步。
