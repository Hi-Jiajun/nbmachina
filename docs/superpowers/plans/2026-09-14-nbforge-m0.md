# nbforge M0「修数据」Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把不可信的输入数据修成可信的 `score.json`（八度标定、去撞格、音级恢复、力度换口径），并用综合评分给出量化基线。

**Architecture:** 纯离线 Node 脚本，模块之间只通过 JSON/CSV 文件通信；每一步都有 `report.json` 记录降级项；用 `verify` 的分数对比"修前/修后"。

**Tech Stack:** Node 22+（零依赖）、WAV（PCM）直接读写、FFT 自实现（Goertzel/窄带能量）、无头 Minecraft 服务器做端到端验收。

**Spec:** `docs/SPEC.md`（本计划从 spec 推导）

---

## 文件结构（M0 新增/修改）
```
src/ingest/wav.mjs            WAV 读写（已有 analyze/wav-rms.mjs 基础上补齐）
src/analyze/octave-evidence.mjs   逐音在候选八度上的窄带能量（八度证据）
src/analyze/chroma.mjs            音级能量分布（用于音级恢复与相似度）
src/arrange/dedupe.mjs            撞格检测与合并策略（含报告）
src/arrange/octave-fix.mjs        用八度证据重写 midi（旋律/贝斯分别处理）
src/arrange/velocity.mjs          力度换口径（窄带能量 → 0..1）
src/verify/score.mjs              客观指标 + 综合分，输出 report.json
tests/*.test.mjs                  node:test 单元测试
```
